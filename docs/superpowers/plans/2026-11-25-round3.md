# Round 3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the owner's round 3 bugs, make every Views/Reverse puzzle fair (no needed cube hidden from both front and back), remove Classic and Sections, and redesign the level list.

**Architecture:** A new pure module `src/core/visibility.ts` holds the 180° turn and the fairness rule; the generator and `scripts/generate-puzzles.ts` use it, and `public/puzzles.json` is regenerated. A one-time purge in `src/ui/storage.ts` deletes saved data of the old puzzles. UI tasks are local to their screens.

**Tech Stack:** TypeScript, Vite, Vitest (jsdom, fake-indexeddb), Playwright e2e.

**Spec:** `docs/superpowers/specs/2026-11-25-round3-design.md`

## Global Constraints

- Branch `round3`; one commit per task; tests first for logic in `src/core` (CLAUDE.md).
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Do not change things outside the spec.
- Sizes are written `W×D×H` with the `×` sign, e.g. `3×3×2` (W = cols, D = rows, H = maxH).
- Puzzle ids keep their formats: Views `L<level>-NNN`, Reverse `RL<level>-NNN` (solved as `R-RL…`), Shadows solved `S<level>-L<level>-NNN`.
- No new dependencies.
